Frozen before calls on 2026-09-27 at product commit `8f24ba3`, branch `v2`.
Run exactly the three questions in [frozen-cases.json](frozen-cases.json) once in
each of `single` and `planned` mode. Keep their original file scopes and expected
facts. Alternate mode order by question, concurrency one, retries zero. Use the
production HTTP/SSE route and current configured models with the previous run's
180-second provider timeout. Do not tune code, prompts or budgets during this run.

Compare with the same six requests from
the [prior repaired pass](../20260927-v2-pdf-live/repair-1/protocol-addendum.md).
Changes since that pass are ranked child fallback, adjacent table units, and
assessor passage-ID selection. Models and stochastic plans can vary; one pass on
seen development cases does not establish general accuracy or causal attribution.

The old isolated index's lifecycle check deleted the Apple document. Copy that
inactive index into a new ignored data directory, restore the Apple extraction,
17 children, parent records and original bytes from the immutable snapshot, and
regenerate only those 17 embeddings with the same configured embedding model.
Do not reparse or rechunk. Verify all five documents' extraction/chunk/parent
records against the frozen snapshot before answers. Retain the new vectors and
their hash in the isolated directory and record embedding usage separately.
The original Apple vector bytes are unavailable, so disclose the reconstruction
and compare observed rankings; do not claim byte-identical vector storage.

Keep K=5, hybrid retrieval, the existing BGE reranker and its recorded revision,
the 4,096-token evidence budget, three rounds/six queries and the 8,192-token
planner input cap. Record resolved models, settings, source hashes, inputs,
rankings, packing exclusions, raw structured outputs, SSE events and saved history.
Do not change `.env`, call a paid judge, modify production data or merge `main`.

Review every answer against original page 1 and the exact supplied/cited text.
Use the prior 0 / 0.5 / 1 requested-point and factual paragraph/bullet rubric.
Separate correctness, completeness, relevance, source faithfulness, citation
support and inline citation coverage. Values must align with the right three- or
twelve-month period ending September 28, 2024, and applicable units. Page-4 GAAP
reconciliation may support income, but not sales. A citation on the last bullet
does not cover an earlier uncited bullet. Valid IDs alone do not establish support.
Reviewers are Codex agents, not independent humans. Preserve disagreements and
failures; do not silently repair model responses.

All three questions are answerable. Full refusals count as incorrect abstention;
request errors count as unsuccessful requests, not refusals. Appropriate abstention
on unanswerable cases is not applicable here because this authorized subset has
none. Dense-table, multi-hop, held-out, OCR/figure/formula and genuine-conflict
acceptance remain outside this run.

Scoped gates: all six requests complete; every requested financial point is correct
and complete; factual claims have supporting inline citations with appropriate
periods and units; zero incorrect abstentions or fabricated cited facts; saved
answer/retrieval history matches each response. Report each gate separately.
Passing this subset does not establish overall v2 acceptance or authorize a merge.

Measure first nonempty answer delta and HTTP stream closure separately, including
failed attempts. Report stage distributions, actual provider input/output/cached
tokens, reliability and sequential throughput. Include startup separately and
record local model loading/cache conditions. Billed cost and separately isolated
provider queue time are unavailable unless the provider supplies them. Keep the
complete 20-metric inventory and all artifacts append-only; no automatic reruns.
