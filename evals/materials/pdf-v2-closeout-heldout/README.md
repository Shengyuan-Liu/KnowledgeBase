# Frozen release holdout

Two public, new-to-this-project papers were frozen before application ingestion
and answering. `protocol.json` contains source URLs, hashes, five questions,
original physical-page references, review rubric, and pre-result thresholds.
The screenshots retain the pages inspected by Codex. Native text exports are
reference aids, not indexed documents or request inputs.

The population is a small project holdout, not independent human validation or a
model-pretraining holdout. Do not tune on these results and call the same set
held out again. Formula and figure understanding are not assessed.

Sources: [Attention Is All You Need](https://arxiv.org/abs/1706.03762v7) and
[BERT](https://arxiv.org/abs/1810.04805v2). Original rights remain with the authors;
these private evaluation copies are not relicensed as project software.
