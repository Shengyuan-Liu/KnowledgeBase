# Frozen synthetic dependency fixture

These two original, fictional PDFs isolate an unknown target: an assignment memo
names a laboratory, and a separate register states its calibration interval.
`protocol.json` freezes the question and original-page evidence before ingestion.
Only the question and file scope enter the application, never the expected target.

This is a controller execution test, not a real-world answer-quality benchmark.
The first observed binding failure remains in the matched closeout run. The
release replay uses the same document bytes and question after a generic binding
instruction fix; this set is development material, not a holdout.
