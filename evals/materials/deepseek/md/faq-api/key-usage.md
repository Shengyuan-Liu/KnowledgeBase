# How to view usage by API Keys

Source: https://static.deepseek.com/faq/index.html?lang=en#/question/key-usage
Captured: 2026-09-21T20:08:01.336Z

To view detailed usage for each API key:

1. Log in to the Platform and go to the [「Usage」](https://platform.deepseek.com/usage) page.
2. Select your desired time range from the 「Time」 menu and the key you wish to query from the 「API Key」 menu.
3. You can also click 「Export」 to download the usage zip file. Unzip it to find two csv files; the file titled **amount** contains usage details by Key.
